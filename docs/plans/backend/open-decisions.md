# Open decisions

Assumptions this plan made, each with the default the plan used, one or two alternatives, and the trade-off in one line. Where a decision lives in detail, the file is named.

**D1–D30 are decided (2026-11-11); D31–D41 were added by the 2026-11-12 refinement and accepted by the user the same day with their defaults (ADR-054).** The last column says how: **User** for the user's own call, **CEO** for a call made for the user, "Default accepted" for the plan's default. Only D29 differs from the default (MIT, not Apache-2.0). The decisions are applied in the spec (v2.1, `docs/spec/index.md`) and recorded in `docs/agents/DECISIONS.md` (ADR-024 to ADR-044).

| # | Decision | Default (plan uses) | Alternatives | Trade-off | Decided (2026-11-11) |
|---|---|---|---|---|---|
| D1 | Code shared with rex | **Copy and diverge**; header comment naming the rex commit in each copied file; revisit after M5 ([tech-stack.md](tech-stack.md) §6) | (a) shared module now (`termkit`: codec, daemonctl, paths, testenv, golden, vt10x); (b) mill imports rex's packages directly | Copy is fast and decoupled but fixes must be ported by hand; a shared module dedupes but couples two fast-moving release trains. | **User:** copy and diverge; header naming the rex source commit; revisit a shared module after M5 |
| D2 | TUI framework version | **Bubble Tea v2** (`charm.land/bubbletea/v2` v2.1.1) | (a) v1.3.10 like rex, copy the splash/board verbatim | v2 is where Charm's fixes land; v1 lets rex code paste in unchanged but starts mill on a maintenance-only line. | Default accepted |
| D3 | YAML library | **`go.yaml.in/yaml/v4`** + text-splice editing | (a) `go.yaml.in/yaml/v3` (frozen API, security fixes only); (b) `goccy/go-yaml` | v4 is the maintained line with Node API; v3 is safer-by-age but frozen; goccy has a richer AST but another dialect. | Default accepted |
| D4 | SQLite driver | **`modernc.org/sqlite`** | (a) `ncruces/go-sqlite3` (wazero) | Both CGO-free; modernc is the more proven one, ncruces is closer to upstream SQLite but adds a WASM runtime. | Default accepted |
| D5 | CLI framework | **rex's output kit + stdlib `flag`** (`core.ParseArgs`, golden tests, formats) | (a) cobra; (b) kong | Same feel and tests as rex and no dependency, at the cost of hand-writing nested subcommand dispatch and completion. | Default accepted |
| D6 | Run id format | **128-bit random hex** (32 chars), ordering by `created_at` | (a) UUIDv7; (b) ULID | Random ids make 4-hex short ids unique in practice; time-prefixed ids sort naturally but runs from the same minute share prefixes. | Default accepted |
| D7 | Windows support in v0 | **Tier 2:** builds, unit/integration tests and `--local` smoke in CI from M1; PTY/terminal agents and container runner best-effort until M11 | (a) full parity from M1; (b) no Windows until v1 | Keeps Windows from rotting (rex learned this) without letting ConPTY quirks gate every milestone. | **User:** Tier 2 in v0 (default) |
| D8 | `sh` part on Windows | **Git for Windows `sh.exe`**, else clear error suggesting `exec` or `shell: pwsh` ([execution.md](execution.md) §3) | (a) `mvdan.cc/sh` interpreter in-process; (b) `pwsh -Command` | Real `sh` semantics with an install requirement, vs. no dependency but an in-process shell that complicates process-group kill. | Default accepted |
| D9 | Default input edge when a node references several nodes | **Primary upstream** = the referenced node downstream of all other references; references otherwise only order; ambiguity is lint error M3021 ([engine.md](engine.md) §2) | (a) literal spec: every reference is a data edge (inputs concatenated); (b) require explicit `in:` whenever more than one node is referenced | Matches what §7.5 obviously means; (a) silently mixes item types; (b) is explicit but noisy. | **User:** primary upstream + `M3021` on ambiguity (default) |
| D10 | `stream` mode timing | **Deferred to M7**; v0 ships `batch` and `each` | (a) in M1 | Stream complicates replay, cache and recovery; dogfood targets don't need it. | Default accepted |
| D11 | Workspace on retry | **Reset worktree to the pre-attempt snapshot** unless `retry.keep_workspace: true` | (a) keep whatever the failed attempt left | Clean, reproducible retries vs. letting an agent continue from partial work (cheaper tokens, messier state). | Default accepted |
| D12 | Built-in parts execution | **In-process Go**, proven equivalent by a loopback JSONL conformance suite and `milld part serve <id>` ([protocols.md](protocols.md) §3.5) | (a) every built-in as a subprocess over stdio | In-process is fast and simple; subprocesses prove the protocol by construction but cost a process per `map`. | Default accepted |
| D13 | Secret found in a step-produced artifact | **Redact text artifacts; fail the node (M9205) for binary ones** ([security.md](security.md) §2) | (a) store as-is and warn; (b) quarantine (store encrypted, hide from viewers) | Upholds "secrets never persist" at the cost of altering outputs (e.g. a diff that contains a token). | Default accepted |
| D14 | Artifact store | **Global content-addressed store** with per-run references and mark-and-sweep GC | (a) per-run artifact dirs (spec §6.3 wording) | Dedupe and cheap reruns/cache vs. simpler deletion (rm a run dir) and self-contained run dirs. | Default accepted |
| D15 | Event-log durability | **Sync fsync on state-changing events, 100 ms group commit for the rest**; `F_FULLFSYNC` only for run create/finish on macOS ([storage.md](storage.md) §8) | (a) fsync every event; (b) never fsync | Crash safety where it matters at low cost; (a) is slow on macOS, (b) risks losing write-ahead records. | Default accepted |
| D16 | What `max_wall` counts | **Active time while an engine runs the run** (sleep/daemon downtime excluded) | (a) calendar time since start | A laptop that sleeps doesn't cancel everything on wake vs. a hard real-world deadline. | Default accepted |
| D17 | `--dry-run` and `sh`/`exec` | **Run them** (they work in workspaces); a node can set `destructive: true` to skip in dry runs | (a) skip every `sh`/`exec` in dry runs | Useful dry runs that still execute checks/builds vs. maximal safety with mostly-empty dry runs. | **User:** `sh`/`exec` run unless the node is `destructive: true`; agents, `git.push` and `gh.*` are stubbed (default, plus agents stubbed) |
| D18 | Pipelines in a not-yet-trusted project (fresh clone) | **Untrusted:** visible, triggers never armed, manual runs refused until `mill trust .` ([security.md](security.md) §4) | (a) spec §22 as written: repo pipelines are trusted | Blocks a cloned repo from auto-running code via cron/fswatch, at the cost of one `mill trust .` per project. | **User:** untrusted until `mill trust .` (default) |
| D19 | `mill-part-*` on PATH and MCP tools vs existing ids | **Fill gaps only**; overriding needs an explicit alias/`override = true` | (a) spec §9.4: later sources override earlier | Prevents a stray binary from replacing `sh`; loses zero-config override. | **User:** built-ins win; PATH and MCP fill gaps; override needs an explicit plugin or `mill.part` (default) |
| D20 | Socket path without `XDG_RUNTIME_DIR` (always on macOS) | **`~/.cache/mill/milld.sock`** (same scheme as rex) | (a) `~/.local/state/mill/milld.sock`; (b) `$TMPDIR/mill/milld.sock` | Matches rex and stays short (104-byte limit); (b) is per-user on macOS but long and cleaned by the OS. | **CEO:** `$XDG_RUNTIME_DIR/mill/milld.sock` on Linux, else `~/.cache/mill/milld.sock` (default) |
| D21 | Path conventions on macOS | **Honor `XDG_*` variables on macOS and Linux**, plus `MILL_CONFIG_DIR`, `MILL_DATA_DIR`, new `MILL_STATE_DIR`, `MILL_SOCKET` | (a) fixed `~/.config` etc. like rex (ignores `XDG_*`) | No legacy to strand in mill, so standards-friendly is free; rex chose fixed paths for compatibility. | Default accepted |
| D22 | Daemon socket on Windows | **AF_UNIX** (as rex) | (a) named pipe (spec §16 wording, needs `go-winio`) | One transport and code path everywhere vs. supporting pre-1803 Windows 10. | Default accepted |
| D23 | Default retry policy | **2 retries on `transient`/`rate_limited`, exp backoff, only for idempotent parts or failures marked retryable** | (a) no retries unless configured | Unattended runs survive rate limits by default without re-running side-effecting steps. | **User:** 2 retries on `transient`/`rate_limited`, exp backoff, idempotent/retryable only (default) |
| D24 | `policy.fail_fast` default | **true** (cancel in-flight siblings when a node fails) | (a) false (let siblings finish) | Saves tokens and time vs. collecting partial results from independent branches. | Default accepted |
| D25 | Agent used for the extraction pass (§11.3 step 3) | **Same agent, cheapest priced model**; setting `agents.extract` overrides; `off` disables | (a) a fixed global extractor (e.g. `claude/haiku`); (b) no extraction pass in v0 | No extra setup and stays vendor-neutral vs. predictable cost/quality from one known model. | Default accepted |
| D26 | Daemon stop with live runs | **Treat like a crash** (no drain; recovery rules apply on restart); `--drain` waits up to 10 min ([execution.md](execution.md) §8) | (a) always drain; (b) cancel everything cleanly | One code path ("crash, don't guess") and fast stops vs. never interrupting work. | **User:** crash semantics; `--drain` waits up to 10 min (default) |
| D27 | Plugin registry and signing | **GitHub as registry** (`gh:` sources + a curated index repo); lockfile hashes now, signatures (sigstore keyless) when the hosted registry exists | (a) hosted registry from v0.5; (b) minisign keys now | Ships plugins without running a service; signatures wait until there's a publisher flow. | **User:** GitHub index + lockfile SHA-256; Sigstore later (default) |
| D28 | Go version floor | **go 1.27 (toolchain 1.27.4)** | (a) match rex at 1.26.11 | Current stable and newest stdlib (`os.Root`, `synctest`) vs. identical toolchains across both repos. | **User:** go 1.27, toolchain 1.27.4 (default) |
| D29 | License | **Apache-2.0** (patent grant; fits the open-core shape in spec §25) | (a) MIT (rex has no LICENSE file yet) | Apache protects contributors and users on patents; MIT is shorter and matches most of the Charm ecosystem. | **User: MIT** (not the default). `LICENSE` added |
| D30 | Environment passed to steps | **Allowlist** (`env.passthrough`) + pipeline/node `env` ([execution.md](execution.md) §3) | (a) inherit milld's full environment | Stops unrelated tokens in milld's env leaking into every step vs. "it just works like my shell". | **User:** allowlist + `env.passthrough` + pipeline/node `env` (default) |

| # | Decision | Default (plan uses) | Alternatives | Trade-off | Decided |
|---|---|---|---|---|---|
| D31 | Where the event catalog and the reducer live | **L1: `core/event` (event structs, `log_v`, decoders) and `core/fold` (pure `Apply`)**, used by the run actor, recovery and index rebuild ([layers.md](layers.md) §4 L1) | (a) keep the reducer in `engine` (spec §27.4) and let `store/index` import `engine` as a named upward exception; (b) a second fold inside `store/index` | One pure reducer below both users, no upward import, vs. matching the spec's current layout; (b) risks two folds disagreeing | User: default accepted (ADR-054) |
| D32 | Shared wiring for `milld` and `--local` | **`assemble` (L6, M2)** builds the engine and adapters from a config snapshot; `daemon/boot` and `surface/cli/local` call it; `cli/local` imports nothing else from L3–L6 after M2 | (a) each root wires itself; (b) `cli/local` imports `daemon/boot` | One wiring, so `--local` and the daemon can't drift, and one narrow surface exception, vs. one more package; (b) drags daemon code into `--local` | User: default accepted (ADR-054) |

| D34 | How layering is enforced | **`internal/archtest` (authority, runs in `go test`) + depguard (editor feedback) + forbidigo (owned concerns)**, exact rules in [layers.md](layers.md) §8 | (a) depguard only; (b) `archtest` only | Exact checks, third-party allowlists and an exception ratchet plus fast feedback, vs. less config; (a) can't ratchet or check allowlists, (b) is only seen at test time | User: default accepted (ADR-054) |
| D35 | Metrics and telemetry | **In-process `metrics` registry (L0, stdlib only), exposed through the `Stats` intent; `otel` and `prometheus` as optional sink parts from M7**; traces derived from the event log ([observability.md](observability.md)) | (a) OpenTelemetry SDK in core from M1; (b) only `expvar` over a debug HTTP port | No new core dependency and nothing that can block a run, vs. standard instrumentation everywhere; (b) has no labels and needs a listener | User: default accepted (ADR-054) |
